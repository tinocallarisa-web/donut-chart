YOUTUBE DESCRIPTION — FULL VIDEO
==========================================

A donut answers one question: what share does each part have. Donut & Pie Chart by TCViz writes the same label inside every slice and never cuts it, rounds the percentages so they add up to 100, groups the small categories into an honest Other you can open, and puts the total in the center. With Pro it shows who really gained share against last year, how each category does against its target, an outer Segment ring and one donut per channel.

──────────────────────────────────────────
WHAT IT DOES
──────────────────────────────────────────
Free:
• Donut or pie, inner radius, start angle, space between slices, border
• Labels inside every slice with the same content and size; a label that does not fit is left out, never cut
• Percentages that add up to 100
• An honest Other you can open in the data table
• Legend and data table with their own positions; total in the center; summary sentence; footnotes
• Lasso selection, drilldown, cross-filtering, highlight, bookmarks, report page tooltips
• Conditional formatting (fx), dynamic format strings, on-object formatting, a font for every text
• Keyboard, screen reader, high contrast, patterns, minimum text size, reduce motion; 12 languages

Pro (0.99 USD per user per month or 9.99 per year, no trial):
• Compare with: change in share (Δ pp) and value (Δ %), new and gone, ⚠ where share and value move apart
• Target: % of target with ✓ ≈ ✕, status icons on the slices
• Segment: an outer ring with its own labels
• Small multiples with a shared table of the total
• Annotations per category; six collection style templates

Sample data: Begudes Nord, a fictitious drinks company.
The visual makes no network requests and declares no privileges.
